# 신입사원 온보딩 가이드

## 첫 주 체크리스트

입사 첫 주에 완료해야 할 항목:

- [ ] 인사팀 서류 제출 (신분증, 통장사본, 최종학력증명서)
- [ ] IT팀 계정 발급 요청 (이메일, 슬랙, 지라, VPN)
- [ ] 사원증 수령 및 출입 등록
- [ ] 팀 리더와 1:1 미팅 일정 잡기
- [ ] 개발 환경 세팅 (해당 시)

## 필수 읽을 문서

1. 사내 위키 홈: `wiki.company.com`
2. 조직도: `wiki.company.com/org`
3. 보안 지침: `wiki.company.com/security`
4. 이 문서(온보딩 가이드)

## 복지 혜택

- 점심 식대: 월 15만원 식대 지원
- 도서 구입비: 연 30만원까지 지원
- 건강검진: 연 1회 무료 (입사 6개월 후부터)
- 경조사 지원: 본인 결혼 50만원, 본인 출산 30만원, 부모님 장례 20만원

## 사내 문화

- 회의는 30분 단위로 설정하고, 안건이 없으면 생략 가능
- '실패해도 됨' 문화 — 실험과 학습을 장려
- 금요일 오후는 'No Meeting' 시간으로 운영
- 분기별 회고(Retrospective)를 통해 프로세스를 개선
