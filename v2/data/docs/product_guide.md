# 제품 가이드 — SmartMonitor Pro

## 제품 개요

SmartMonitor Pro는 기업용 환경 모니터링 솔루션이다. 서버, 네트워크 장비, 클라우드 리소스의 상태를 실시간으로 수집하고 이상 징후를 자동 감지한다.

## 주요 기능

### 실시간 대시보드

- CPU, 메모리, 디스크, 네트워크 사용량을 1초 간격으로 갱신
- 커스텀 위젯으로 원하는 메트릭만 표시 가능
- 다크모드/라이트모드 지원

### 알림 시스템

임계값 기반 알림과 이상 탐지(Anomaly Detection) 알림 두 가지를 제공한다.

- 임계값 알림: 사용자가 직접 설정한 기준값 초과 시 발송
- 이상 탐지: 머신러닝 모델이 평소 패턴과 다른 동작을 감지
- 알림 채널: 이메일, Slack, PagerDuty, SMS 연동 가능

### 리포트 자동 생성

매일/매주/매월 단위로 성능 리포트를 자동 생성한다. PDF와 CSV 형식으로 내보낼 수 있으며, 예약 발송 기능도 지원한다.

## 가격 정책

- **Basic**: $29/월 — 최대 10개 호스트, 기본 알림만
- **Pro**: $99/월 — 최대 100개 호스트, 이상 탐지 + 리포트 포함
- **Enterprise**: 별도 문의 — 무제한 호스트, 온프레미스 옵션, 전담 지원

모든 플랜은 14일 무료 체험을 제공하며, 연간 결제 시 20% 할인을 적용한다.

## 설치 방법

1. 모니터링할 서버에 에이전트를 설치한다 (Linux/Windows 지원)
2. 대시보드에서 호스트를 등록하고 수집할 메트릭을 선택한다
3. 알림 규칙을 설정한다

에이전트는 50MB 미만의 경량 바이너리이며, 설치 후 별도 설정 없이 자동으로 데이터를 수집한다.
